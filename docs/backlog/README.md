# Backlog

Staging area for ideas not yet grilled. One file per group; each group is
taken through one session of `/grill-with-docs` → `/to-spec` (one PRD
issue) → `/to-tickets` (slice issues on GitHub), then its file and its
line below are deleted. Groups are ordered for implementation — work top
to bottom unless told otherwise. Delete this directory once it is empty.

Each item carries a feature key (`FEAT-NNN`) — keep it in the issue title
for traceability with older commits.
